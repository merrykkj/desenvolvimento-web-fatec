# Desenvolvimento Web - FATEC

Este repositório foi criado para armazenar e organizar os projetos, exercícios e códigos desenvolvidos durante as aulas da disciplina de Desenvolvimento Web na FATEC. O objetivo é registrar a evolução do aprendizado nas principais tecnologias de front-end.

## Tecnologias Estudadas

O cronograma de aprendizado abrange as seguintes tecnologias:
* HTML5 - Estruturação de conteúdo web.
* CSS3 - Estilização, layouts e design responsivo.
* Angular - Framework para construção de aplicações SPA (Single Page Applications) dinâmicas.
* Bootstrap - Framework de CSS para desenvolvimento ágil e componentes responsivos.

---

## Estrutura do Repositório

O projeto está dividido em módulos semanais e práticos:

* aula-01-html / aula-02-html
  * Inicialização da estrutura base e conceitos fundamentais de tags e semântica do HTML.
* aula-03-html
  * Introdução e aplicação de folhas de estilo (CSS) para design dos elementos.
* aula-04-angular
  * Transição para o ambiente Angular, configuração do ecossistema e componentização.
* aula-05-bootstrap/web05
  * Integração do Bootstrap ao projeto, criação de vitrines de produtos com descrições e preços estruturados.
* loja-virtual
  * Projeto prático integrando os conhecimentos adquiridos, com foco na refatoração e estruturação lógica do componente de cabeçalho (header).

## Como Executar os Projetos

### Páginas Estáticas (HTML/CSS/Bootstrap)
1. Clone o repositório:
   ```bash
   git clone https://github.com
   ```
2. Navegue até a pasta da aula desejada (ex: aula-03-html).
3. Abra o arquivo index.html diretamente em seu navegador.

### Projetos Angular (aula-04 em diante / loja-virtual)
1. Certifique-se de ter o Node.js e o Angular CLI instalados.
2. Navegue até a pasta do projeto correspondente:
   ```bash
   cd loja-virtual
   ```
3. Instale as dependências locais:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   ng serve
   ```
5. Acesse http://localhost:4200/ no seu navegador.
